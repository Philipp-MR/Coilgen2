# Browser workbench fixes and repeat validation

The [original audit](REPORT.md) records the behavior before these changes. The [new-user guide](../../docs/BROWSER_WORKBENCH.md) follows the controls in the revised workbench from the Windows launcher through an editable project and a CAD export.

**All 29 full evaluations for the retained templates completed and matched their submitted request digests.** Verification covered 616 artifact entries and 3,660 stored arrays. All numeric arrays were finite. All 29 designs passed their sheet checks and failed both swept-conductor and fabrication review. No record carried a construction release. [Case-by-case results](retest-matrix.csv)

## Interface decisions and engineering impact

| Step | Simplification or correction | Engineering check |
|---|---|---|
| Start | The gallery explains the support, target and winding objective of each template. | Readiness, job completion, engineering checks and construction release have separate labels. |
| Edit | **Model settings** opens a drawer. Only parameters for the chosen support appear. Dirty fields expose **Apply** and **Discard edits**. Save and Compute wait for a decision. | A 135 mm cylinder radius reached the persistent model as 0.135 m. Cylinder length displays the physical 200 mm span. Refining the axial mesh preserves the span. |
| Compute | **Compute** applies the displayed boundary to the editing channel. **Compute enabled channels** applies that same boundary to the enabled channels. Each uses its own model, solver controls and validation settings. | Duplicating creates a fresh project ID. Disabling a channel excludes it from batch submission. Completed progress bars reach 100%. Preparation reports the sheet, sweeps and fabrication as **Not run**. |
| Inspect | The active model and selected result each show their name, revision and source. Switching models clears the visible result and CAD choices. Earlier work remains in **Show runs from other projects and channels**. | Historical field plots used the selected result’s recorded B0. The model preview used the editing model’s direction. |
| Save and reopen | The workbench restores verified workspace history. **Save project** writes a compact, self-contained `.coilgen` file. **Save JSON** retains a readable interchange format. **Download project** retrieves the selected save. **Reopen saved project** continues a workspace project after restart without uploading it again. | Completed runs, owned input bytes and exact source revisions accompany the project. A first save of an independent design cannot overwrite a different same-name design. |
| Export | CAD names and companions come from the selected run. If its exact inputs are unavailable, the browser offers a deliberate geometry-only handoff. DRAFT solids require acknowledgment. | Cross-project export checks verified that the selected geometry and its companion named the same source revision. |
| Share | A participant supplies both the host's team password and a private workspace passphrase. Creation and reopening are separate. Old or unclaimed workspaces require host enrollment. | A name collision or the shared password alone cannot reclaim an existing workspace. Replacing a server-side filename cannot change a saved run's inputs. |

## Numerical interpretation

- The Halbach gallery uses the same 0.05 T vector for its MRI B0 and its uniform mechanical load case. Deliberately independent load cases remain configurable. On the original Gx currents, changing the uniform background from 3 T to 0.05 T scales torque about x from about −0.01469 N·m to −0.0002448 N·m.
- Shield suppression now reports physical RMS and peak residuals on the original design surface. Its sheet and fabricated-field results have separate verdicts. The conic solver norm includes vertex area, so it needs area normalization before comparison with a specification in tesla. The old shielded Gy record yielded 19.999 µT for the sheet, 29.525 µT for the winding and a fabricated peak of 83.500 µT. Independent surface coverage requires a separate holdout.
- The rejected gradient studies have physical geometry violations. For example, the original cylindrical Gy body achieved a 1.447 mm minimum bend radius against a 6 mm requirement. Its centerline margin was −3.074 mm against a 3.078 mm required spacing. The fixes preserved the configured bend and spacing limits.

## Validation evidence

The repeat test submitted full evaluations for the same 17 retained standalone templates and all 12 system channels from the Codex internal browser. The suite also exercises project transfer, workspace recovery, historical CAD, physical dimensions, invalid input, partial boundaries and team isolation. [Final run matrix](retest-matrix.csv)


- On a 595 px viewport, the main pane and document both fit the 580 px available beside the scrollbar. Settings, design, result and export controls remained usable. The original pane required 708 px.
- The browser returned HTTP 200 for the DRAFT ZIP with its attachment filename and expected bytes. The ordinary click-to-download automation event did not consistently report receipt.
- The supplier Gy STL completed preparation as an owned metric mesh. The two-channel prepared batch recorded only Gx and Gy, each with all later checks **Not run**. Separate sheet, contour and routed submissions completed. Cancelling a live evaluation produced **Cancelled** with no completed result to export.
- A synthetic neighboring-workspace STL path and a Python attribute expression were rejected before changing the model. `sin(x) + cos(y)` was accepted. Uploaded bundles and JSON are checked before loading sidecars, previewing expressions or restoring nested evidence. Transfers are confined to the user's workspace and bounded in both uploaded and expanded size.
- New Halbach Gx displayed 0.05 T for both MRI and mechanical fields. Explicitly configuring a separate 3 T mechanical case produced a nonblocking readiness warning with both physical vectors. The shielded result displayed 19.999 µT sheet RMS (pass) and 29.525 µT fabricated RMS (fail) against 20 µT on 314 design samples. [Shielded Gy result](retest-shield-result.jpg)
- The corrected Gx evaluation measured −0.00024484078 N·m about x. The earlier run recorded −0.014690447 N·m. Both field/load inputs and the signed torque are retained in the run records.
- All 29 studies used identical 3,112-point holdout grids and target samples to their matched baselines. Independent B∥ sheet RMS ranged from 2.984% to 4.310%. The largest pointwise field difference was 3.16 × 10⁻¹⁴ T on shielded Gy. Baseline sheet, sweep and fabrication verdicts agreed in every case.
- In the 21 comparisons with two native threads in both runs, the stored review centerlines were identical. The other eight comparisons had 20 threads in the earlier run and two in the repeat. The largest difference in world coordinates was on cylindrical system Gz, **10.17 mm** sampled path-set Hausdorff distance for review paths sampled at no more than 0.1 mm. Both Gz geometries failed fabrication. Thread policy and software version differed in those eight comparisons, so the study cannot attribute the difference to thread count alone. Pin `--threads-per-worker` when studying changes to routing.
- The campaign requested two native threads. Its NumPy and SciPy pools used two, but an inactive SCS OpenBLAS pool reported 20. The launcher now sets BLAS and OpenMP limits before importing numerical libraries.
- A participant created a private workspace, saved a project, restarted the hub and reopened the saved revision and result. A duplicate workspace name with different capitalization could not claim the original workspace. A wrong private passphrase also failed. A full Gy solve completed while the participant was logged out across the idle-reaper interval.
- The full test suite passed **5,859 tests and 26 subtests** in 35 minutes, with eight Matplotlib/Qt deprecation warnings. A separate 241-test run covered browser, CAD, project/session, numerical and worker behavior. The tests that had failed during the earlier mixed-code suite were included in the repeat. After the final interface and worker-environment changes, the 66 browser, input-policy, setup and preflight regressions passed together. Ruff passed, and all four guides' relative links resolved.

The final numerical source SHA-256 was `2d0dc75ed566646d0ddb1b9f155aefa23cc2d0c2d82c381cecf91788b8870f98`. The campaign and comparisons used isolated test directories. The case matrix retains the raw job locations on this Windows host. All temporary test hubs and worker processes were stopped. Direct execution of the separate script studies and physical hardware qualification were outside this browser validation.
- The Windows setup launcher found an existing configured or shared Python environment with no Python on PATH. Its non-installing `--help` check also worked in a checkout name containing spaces, parentheses and an ampersand. An isolated offline wheel installation served the upload widget with the same bytes as the source checkout. The four installation/workbench guides had 42 valid relative links at the document review.

An earlier repeat overlapped source edits and a change to the worker protocol. Five jobs completed normally, twelve wrote scientific records with a different runtime digest from the submitted request, and twelve stopped without a verified result. Those attempts retain their original status. The worker now pins numerical source identity before solving, checks it again at completion and reports when a new submission is required. Browser presentation changes no longer invalidate a numerical request. [During-edit attempts](retest-during-edits.csv)
