# Primitive Support Structures

This project contains small CoilGen examples for exploratory support-surface
geometries. The scripts are intended for direct Spyder use by MR scientists:
edit the `PARAMETERS` object near the top of the script and run the file.

## Script

- `scripts/run_primitive_support_designs.py`

The script can validate or run these generated support surfaces:

- `circular_disc`: one filled circular planar surface;
- `annular_disc`: one planar ring with a central access hole;
- `partial_cylinder`: an open cylindrical sector;
- `elliptical_cylinder`: an open elliptical cylinder;
- `superellipse_cylinder`: a rounded-rectangle / superellipse cylinder;
- `spherical_cap`: a cap surface for head-like/local supports;
- `ellipsoidal_cap`: an anatomy-conformal ellipsoidal cap;
- `conical_frustum`: a tapered cylindrical support;
- `toroidal_segment`: a curved toroidal support segment;
- `ruled_surface`: a surface between two user-defined 3D curves;
- `surface_of_revolution`: an axisymmetric surface defined by `(z, radius)`
  profile samples.
- `parametric_surface`: an arbitrary sampled `surface(u, v)` function.
- `shielded_annular_disc`: annular primary plus same-topology active shield
  generated by outward normal offset.

By default only `annular_disc` is selected and CoilGen runs a low-resolution
y-gradient design. To run multiple primitive cases, edit:

```python
PARAMETERS = object_parameters({
    "run": {"selected_cases": ("partial_cylinder", "superellipse_cylinder")},
})
```

For faster configuration checks without numerical optimization, set:

```python
"run_design": False
```

All dimensions are SI units. The default mesh and target resolutions are small
on purpose; increase them only after the geometry and target field are correct.
